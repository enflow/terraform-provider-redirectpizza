# redirectpizza_redirect (Resource)

Manages a redirect.pizza redirect. One redirect can map many source hostnames to one or more destinations.



## Example Usage

```terraform
resource "redirectpizza_redirect" "example" {
  sources = [
    "old-domain.com",
  ]

  destination {
    url = "https://new-domain.com"
  }

  # Optional. One of: permanent, temporary, permanent:308, temporary:307, frame
  redirect_type = "permanent"

  tracking          = true
  uri_forwarding    = true
  keep_query_string = false
  tags              = ["prod", "legacy"]
}

# Dynamic destinations: all but the fallback need an expression.
resource "redirectpizza_redirect" "geo" {
  sources = [
    "old-dynamic-source.com",
  ]

  destination {
    url        = "https://new-fancy-site.nl"
    expression = "country == 'NL'"
    monitoring = "enabled"
  }

  destination {
    url        = "https://new-fancy-site.us"
    expression = "country == 'US'"
    monitoring = "disabled"
  }

  destination {
    url = "https://new-fancy-site.com"
  }
}
```

## Schema

### Required

- `destination` (Block List, Min: 1) Destination URLs. Order is significant for dynamic destinations. When more than one destination is set, all but the fallback must include an expression. (see [below for nested schema](#nestedblock--destination))
- `sources` (Set of String) Source hostnames or URLs visitors enter in their browser.

### Optional

- `keep_query_string` (Boolean) Whether the query string should be forwarded to the destination URL.
- `redirect_type` (String) Redirect type. One of `permanent` (301), `temporary` (302), `permanent:308`, `temporary:307`, or `frame`.
- `tags` (Set of String) Tags used to categorize this redirect.
- `tracking` (Boolean) Whether analytical information should be collected.
- `uri_forwarding` (Boolean) Whether the path should be forwarded to the destination.

### Read-Only

- `id` (String) The ID of this resource.
